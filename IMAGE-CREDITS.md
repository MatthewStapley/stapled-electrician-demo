# Image credits

## Made for this concept

These were all made for this project, so no third-party licence applies.

- `kitchen-*`: rendered by the code in `scripts/render/`. Labelled "Illustrative
  visualisation" on the site.
- `consumer-unit.webp` and `test-sheet.webp`: built from the HTML in
  `scripts/art/`. Labelled "Illustrative image". The consumer unit is a generic
  drawing with no manufacturer's branding. Every test figure is invented, and
  the sheet is marked as a specimen.
- The wall elevation, menu and brand mark are hand-coded SVG or CSS.

They show no real installation.
